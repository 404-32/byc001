# Third-party notices

The MoonBit module depends on:

- `moonbitlang/async` 0.22.5, Apache-2.0
  - Repository: https://github.com/moonbitlang/async
  - Used by the CLI for asynchronous file reading.

No third-party parser source code is vendored in this repository. PE/COFF format
behavior is implemented from the public Microsoft PE/COFF specification.
