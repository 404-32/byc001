# Fixtures

The two binary fixtures are deterministic synthetic PE files generated by
`scripts/generate_fixtures.py`.

- `minimal-pe32.exe` contains a section, imports, exports, resources, relocation,
  delay-import, TLS, debug, load-config, and exception directories.
- `minimal-pe32plus.exe` exercises the PE32+ optional-header layout.

Regenerate them with:

```bash
python scripts/generate_fixtures.py
```
